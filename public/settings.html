系统设置登录

请输入设置页秘钥以继续。

API Key 鉴权

要求访问 /v1/* 接口时携带 API Key
以 Authorization: Bearer 请求头发送。开启鉴权且列表为空时会自动生成。
访问本设置页所需的秘钥，默认 admin；留空则关闭设置页鉴权。

默认偏好

MT 模型始终携带 source_lang / target_lang，客户端未传时使用这里的默认值。

上游与服务

配置文件：config.yaml

OpenAI 兼容调用

MT 模型接受 source_lang / target_lang；Chat 模型会忽略它们。 
curl http://localhost:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_KEY" \
  -d '{
    "model": "index-mt-9b",
    "source_lang": "auto",
    "target_lang": "zh",
    "messages": [{"role": "user", "content": "Hello, world"}],
    "stream": true
  }'
